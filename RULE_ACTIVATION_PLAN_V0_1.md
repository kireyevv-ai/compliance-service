# RULE_ACTIVATION_PLAN_V0_1.md

## Принцип

Legal Rulebase содержит 50 правил, но runtime не должен активировать правило, пока scanner не умеет получить достаточные Facts/Evidence.

Количество правил в файле ≠ количество активных правил в первой сборке.

Всего: **15 правил**.

Почему именно они:
- опираются в основном на статический HTML/HTTP;
- дают понятное evidence;
- не требуют имитировать действия пользователя;
- не требуют semantic AI;
- не требуют знания внутренних бизнес-процессов.

### Важно

`CON-001` и `CON-002` остаются `WARNING`, а не автоматическим `FAIL`, согласно Rulebase.

## Правило активации

Перед переводом Rule в runtime ACTIVE:

1. scanner производит все обязательные facts;
2. есть достаточное evidence;
3. есть golden cases;
4. regression tests проходят;
5. для `FAIL` исключены известные критические false positives;
6. если правило юридически чувствительное — выполнено экспертное ревью.
